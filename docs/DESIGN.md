## 2. Три направления

### A. «Каталожный ящик» — **выбрано**
Сайт выглядит как ящик библиотечного каталога. Рабочая зона лежит на манильном картоне, каждый контакт — карточка с красной линейкой и голубыми строками, а данные «напечатаны» моноширинным шрифтом, как на машинке. Сопоставление колонок — коммутационная панель: слева гнёзда с буквами колонок A, B, C, справа поля vCard, между ними шнуры. Заголовки разделов оформлены как латунные этикетки на ящиках. Теней нет: всё держится на линиях и рамках.

- Палитра: манила `#EDE3C8`, картон карточки `#FFFDF6`, тушь `#1D1C1A`, красная линейка `#C0392B`, голубые строки `#A8C2DD`, синий для действий `#1E4FA8`. Тёмная тема: «ящик ночью» — орех `#191712`, карточки `#24211B`, светлая тушь `#EEE7D6`.
- Шрифты: **IBM Plex Sans** (гротеск: интерфейс и заголовки) + **IBM Plex Mono** (данные, карточки, этикетки). Лицензия SIL OFL. Семейство Plex покрывает латиницу, кириллицу, греческий и вьетнамский, а Plex Sans Arabic, Devanagari, JP и KR дают единый ритм для имён на любой письменности. Это функциональная причина выбора, а не вкусовая.

### B. «Телефонный справочник»
Плотная газетная вёрстка белых страниц: три колонки, имена жирным, номера с точками-отточиями, буквенный указатель на обрезе. Палитра: газетная бумага `#F3F1EA`, чёрный, сигнальный жёлтый `#F2C200` для выделений. Шрифты: PT Sans Narrow + PT Mono (ParaType, OFL, сильная кириллица). Первый экран: строка ввода как шапка справочника, результат — колонки листинга.
*Почему не выбрано:* жёлтый с чёрным слишком близок к фирменному стилю «Жёлтых страниц» (товарный знак во многих странах). Узкий шрифт хуже читается в арабском и в CJK-именах. Метафоре справочника не хватает операции «сопоставить колонки».

### C. «Ведомственный бланк»
Сайт как форма: пронумерованные секции 1–4 в рамках, поля с номерами, гребёнки для символов, статусы-штампы красно-оранжевым `#D9480F`. Шрифты: Golos Text (гротеск Госуслуг) + JetBrains Mono. Первый экран: «Форма CV-3.0», четыре пронумерованных блока сверху вниз.
*Почему не выбрано:* бюрократическая интонация отпугивает, а люди приходят с простой задачей — перенести контакты в телефон. Golos не покрывает вьетнамский (фаза 2). У бланка нет естественного места для предпросмотра результата.

**Итог: A.** Метафора один к одному совпадает с предметом: vCard — это и есть карточка контакта. Коммутационная панель естественно объясняет сопоставление колонок. Ни один конкурент не выглядит похоже: у всех белые SaaS-карточки с тенями.

## 3. Токены

Все токены лежат в `apps/web/src/styles/tokens.css` как CSS-переменные, тёмная тема переопределяет их. Страница `/styleguide/` (noindex) показывает каждый токен и компонент.

- **Цвет:** `--paper` (манила), `--paper-2` (тень манилы для полос), `--card`, `--ink`, `--ink-2` (вторичный текст, контраст ≥ 7:1 на `--card`), `--ink-3` (подписи, ≥ 4.5:1), `--rule` (красная линейка; это же цвет ошибок), `--line-blue` (голубые строки, только декор), `--action` (синий — единственный смысловой акцент: кнопки, ссылки, фокус), `--action-ink` (текст на синем), `--hairline`.
- **Типографика:** база 16 px; шкала 1.25 — `--fs-0` 12.8, `--fs-1` 14, `--fs-2` 16, `--fs-3` 20, `--fs-4` 25, `--fs-5` 31, `--fs-6` 39. Начертания 400/600 для Sans, 400/500 для Mono. Табличные цифры (`font-variant-numeric: tabular-nums`) во всех данных.
- **Отступы:** шаг 4 px: `--s-1` 4 … `--s-8` 64.
- **Радиусы:** `--r-0` 0 (по умолчанию), `--r-card` 2 px — скругление угла картона, не «таблетки».
- **Линии:** `--bw-hair` 1 px, `--bw-rule` 2 px (красная линейка, рамки секций), `--bw-heavy` 3 px (активный элемент).
- **Движение:** `--t-fast` 120 ms. При `prefers-reduced-motion: reduce` все переходы выключены.

## 4. Правила вёрстки

- Только логические свойства (`margin-inline`, `padding-block`, `inset-inline-start`, `text-align: start`): арабский во второй фазе включается атрибутом `dir="rtl"` без переделки CSS.
- Теней нет. Глубина задаётся рамкой 1–2 px и сдвигом карточек в стопке.
- Фокус всегда виден: обводка 3 px `--action` с отступом 2 px.
- Шрифты self-hosted в woff2 с `unicode-range`. Браузер качает только нужные подмножества (latin, latin-ext, cyrillic, greek, vietnamese). Preload — только основное начертание основного подмножества для языка страницы. У запасного шрифта (Arial/Helvetica) метрики подогнаны через `size-adjust: 101.4 %`, `ascent-override: 101.1 %`, `descent-override: 27.1 %`, чтобы при подмене не прыгала вёрстка.
- CJK: свои Noto CJK не подключаем. Один вес Noto Sans SC или JP — это 4–8 МБ даже в нарезке, а Docker-образ ограничен 60 МБ. Во всех ОС есть системные CJK-шрифты (PingFang, Hiragino, Yu Gothic, Microsoft YaHei, Malgun Gothic, Noto CJK на Android), они стоят в font-family после Plex. Арабский (IBM Plex Sans Arabic) и деванагари (Noto Sans Devanagari) — self-hosted с `unicode-range`, качаются только при наличии таких символов.

## 5. Проверка по списку «запрещено»

Проверены все типы экранов: инструмент с образцом и с загруженным файлом, гайд, статья, юридическая страница, 404, локализованные страницы, тёмная тема. Ширины 375, 768 и 1440 px.

| Запрещено | Результат |
|---|---|
| Фиолетово-синие градиенты, «стекло», размытые пятна, неон | Нет. Градиентов нет вообще, фон — плоская манила; в тёмной теме — орех без свечения |
| Шаблон «огромный заголовок по центру → 3 карточки преимуществ → отзывы → тарифы» | Нет. Заголовок выровнен влево, сразу под ним работающий инструмент; дальше шаги, таблица возможностей и ограничений, формат, FAQ |
| Одинаковые скруглённые карточки с мягкой тенью | Нет. `box-shadow` в CSS не используется. Радиус 2 px только у картона карточек. Глубина — рамки 1–2 px |
| Эмодзи и ✨ вместо иконок, 3D и «технологичные» картинки | Нет. Иконка одна — SVG переключателя темы. Эмодзи встречаются только в тестовых данных и в примере folding в тексте |
| Inter, Geist, system-ui на всём; слабая иерархия | Нет. IBM Plex Sans + IBM Plex Mono, self-hosted. Иерархия: H1 39 px / 600, H2 25 px, моноширинные этикетки-капслок для разделов и данных |
| «Unleash», «Supercharge», «Seamless», «Effortless», «AI-powered», «в пару кликов!» | Нет (проверено `grep` по всем 152 страницам и 8 словарям). Переводчикам маркетинговая лексика была запрещена в задании |
| Выдуманные отзывы, счётчики пользователей, «нам доверяют» | Нет |
| Первый экран — реклама инструмента | Первый экран — сам инструмент. Демо-таблица и карточки отрендерены в HTML ещё до загрузки JS |
