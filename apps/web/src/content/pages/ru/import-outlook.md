## Какой файл для какого Outlook

| Outlook | Лучший файл | Путь |
| --- | --- | --- |
| Новый Outlook для Windows, Outlook.com, Outlook в браузере | Outlook CSV | «Люди» → «Управление контактами» → «Импорт контактов» |
| Классический Outlook для Windows (2016–2024, Microsoft 365) | Outlook CSV | «Файл» → «Открыть и экспортировать» → «Импорт и экспорт» |
| Outlook для Mac | .vcf (vCard 3.0) | Перетащить на «Люди» или «Файл» → «Импорт» |
| Один контакт в любой Outlook | .vcf | Открыть файл → «Сохранить и закрыть» |

## Классический Outlook: мастер импорта

1. **Файл** → **Открыть и экспортировать** → **Импорт и экспорт**.
2. Выберите **Импорт из другой программы или файла** → **Далее**.
3. Выберите **Значения, разделенные запятыми** → **Далее**.
4. Укажите CSV через «Обзор». Выберите, что делать с дубликатами: *Заменять дубликаты при импорте*, *Разрешить создание дубликатов* или *Не импортировать дубликаты* → **Далее**.
5. Выберите папку **Контакты** нужной учётной записи → **Далее**.
6. Отметьте действие для файла. Если Outlook не на английском, нажмите **Сопоставить настраиваемые поля**, проверьте, что каждая колонка попала в нужное поле, затем **ОК** → **Готово**.

## Что в Outlook CSV из этого конвертера

Колонки называются так же, как в выгрузке самого Outlook (в английской версии): `First Name`, `Last Name`, `Mobile Phone`, `Business Phone`, `E-mail Address`, `Company`, `Job Title`, `Business Street`, `Birthday` и так далее. Телефоны раскладываются по колонкам в соответствии с типом. Лишние номера уходят в *Other Phone*, *Car Phone* и *Callback*. Всё, что не помещается (четвёртый e-mail, четвёртый адрес), добавляется в *Notes*, а не теряется. Дни рождения записываются как `M/D/YYYY` — в том виде, в каком их выгружает сам Outlook.

## Если нужно всего несколько контактов

Откройте каждый .vcf (выберите в конвертере «ZIP, по .vcf на каждый контакт»). Outlook покажет окно контакта — нажмите **Сохранить и закрыть**. Для десяти контактов это нормально, для тысячи — утомительно.
