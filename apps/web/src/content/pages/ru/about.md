## Что это

csvtovcf.com превращает списки контактов из Excel, Google Таблиц, Google Контактов, Outlook, LinkedIn или любой CRM в файлы **vCard (.vcf)**, которые импортируют телефоны и почтовые программы. Он появился потому, что существующие варианты были либо платными программами для компьютера с пробной версией на десять контактов, либо сайтами, которые загружают вашу адресную книгу на сервер и угадывают колонки.

**Факты:**

- Запуск: ноябрь 2026 года. Дата последнего обновления этой страницы указана ниже.
- Языки: английский, испанский, португальский (Бразилия), индонезийский, турецкий, немецкий, французский, русский.
- Форматы: на входе CSV, TSV, XLSX, XLS, ODS; на выходе vCard 2.1, 3.0, 4.0, Google CSV и Outlook CSV.
- Цена: бесплатно, без регистрации, без ограничения по числу строк.

## Как это работает

Страница загружается один раз. Дальше каждый шаг — чтение файла, определение кодировки, сопоставление колонок, очистка номеров, запись vCard — выполняется в Web Worker в вашем браузере. Ничего не загружается на сервер, а после первого открытия конвертер работает офлайн. На [странице о конфиденциальности](/ru/konfidencialnost/) подробно описано, что передаётся по сети, а что нет.

Движок конвертации открыт под лицензией MIT: [github.com/itensity-dev/csvtovcf](https://github.com/itensity-dev/csvtovcf), в npm — пакет [`csvtovcf`](https://www.npmjs.com/package/csvtovcf). Номера телефонов проверяются библиотекой [libphonenumber-js](https://gitlab.com/catamphetamine/libphonenumber-js), таблицы читаются с помощью [SheetJS](https://sheetjs.com/). Все библиотеки и шрифты перечислены на [странице лицензий](/ru/licenzii/).

## Кто это делает

csvtovcf делает независимый разработчик, у которого есть и другие инструменты для одной задачи: [ibangenerator.io](https://ibangenerator.io/), [metasnitch.com](https://metasnitch.com/), [woff2tottf.com](https://woff2tottf.com/), [vtttosrt.com](https://vtttosrt.com/) и другие — их список есть внизу каждой страницы. Каждый из них делает одно дело и не требует регистрации.

## Контакты

Ошибки, неверно сопоставленные колонки, телефон, который не хочет импортировать файл: пишите на **hello@csvtovcf.com** или откройте issue на [GitHub](https://github.com/itensity-dev/csvtovcf/issues). Если файл конвертируется неправильно, опишите его колонки и придуманную строку для примера — пожалуйста, не присылайте настоящие контактные данные.

csvtovcf не связан с Apple, Google, Microsoft, Samsung или LinkedIn; названия их продуктов используются только для описания совместимости.
