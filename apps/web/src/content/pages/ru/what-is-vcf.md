## Что внутри

vCard — это текст. Каждая карточка начинается с `BEGIN:VCARD` и заканчивается `END:VCARD`; каждая строка между ними — одно свойство:

```text
BEGIN:VCARD
VERSION:3.0
N:Петров;Иван;Сергеевич;;
FN:Петров Иван Сергеевич
TEL;TYPE=CELL:+79991234567
EMAIL;TYPE=INTERNET,WORK:petrov@example.ru
ORG:ООО «Пример»
ADR;TYPE=WORK:;;ул. Тверская\, д. 1;Москва;;125009;Россия
BDAY:1990-05-17
NOTE:Познакомились на выставке
END:VCARD
```

Самые распространённые свойства:

| Свойство | Значение |
| --- | --- |
| `N` | Части имени: фамилия; имя; отчество или второе имя; приставка; суффикс |
| `FN` | Отображаемое имя |
| `TEL` | Номер телефона с типами вроде `CELL`, `WORK`, `HOME`, `FAX` |
| `EMAIL` | Адрес e-mail |
| `ADR` | Адрес: абонентский ящик; доп. адрес; улица; город; регион; индекс; страна |
| `ORG`, `TITLE` | Компания (и отдел), должность |
| `BDAY`, `ANNIVERSARY` | Даты |
| `NOTE`, `URL`, `CATEGORIES` | Заметка, сайт, группы |

## Три версии

| | vCard 2.1 | vCard 3.0 | vCard 4.0 |
| --- | --- | --- | --- |
| Опубликована | 1996, консорциум Versit | 1998, [RFC 2426](https://www.rfc-editor.org/rfc/rfc2426) | 2011, [RFC 6350](https://www.rfc-editor.org/rfc/rfc6350) |
| Нелатинский текст | `CHARSET=UTF-8;ENCODING=QUOTED-PRINTABLE` | UTF-8 по умолчанию | только UTF-8 |
| Параметры типа | `TEL;CELL;VOICE` | `TEL;TYPE=CELL` | `TEL;TYPE=cell`, номера как URI `tel:` |
| Обязательные поля | `N` | `N`, `FN` | `FN` |
| Где встречается | старые телефоны, некоторые выгрузки с Android | iPhone, Android, Google, Outlook | серверы CardDAV, новые приложения |

**vCard 3.0** — надёжный выбор: эту версию экспортируют iOS и Google Контакты, и её читает любая программа импорта. **4.0** наводит порядок в формате (например, дни рождения без года записываются как `--0517`, номера — как `tel:+79991234567`), но программы импорта обрабатывают её не так единообразно. **2.1** важна для телефонов 2000-х: они не понимают UTF-8, если каждое значение с нелатинскими буквами не закодировано в Quoted-Printable.

## Детали, на которых ломается импорт

- **Окончания строк** должны быть CRLF.
- **Длинные строки** переносятся на 75 байтах: строка обрывается, а следующая начинается с пробела. Плохой конвертер разрезает многобайтовую букву пополам — а каждая буква кириллицы в UTF-8 занимает два байта, — и посреди имени появляется `�`.
- **Запятые и точки с запятой** внутри значений нужно экранировать (`\,` `\;`), иначе адрес вроде «ул. Ленина, д. 5, кв. 12» развалится на части.
- **Кодировка:** файл vCard 3.0, записанный в Windows-1251 вместо UTF-8, на любом телефоне покажет кириллицу кракозябрами.

[Конвертер на этом сайте](/ru/) записывает всё это правильно в каждой версии, а точный текст первой карточки можно посмотреть до скачивания на вкладке *Текст vCard*.
